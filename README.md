# 🪙 CryptoVault - Dashboard para Inversores

Un dashboard moderno, rápido y optimizado para el seguimiento y análisis de criptomonedas en tiempo real. Diseñado especialmente para comunidades de trading e inversores que buscan una interfaz limpia y funcional.

## 🚀 Características Principales

* **Monitoreo en Tiempo Real:** Precios del mercado cripto actualizados automáticamente cada 30 segundos.
* **Interfaz Premium:** Diseño oscuro (*Dark Mode*) de alta gama optimizado con Tailwind CSS.
* **Calculadora de Gas Fees:** Estimación en tiempo real del costo de transacciones para la red BNB Smart Chain (BEP-20).
* **Gráficos de Tendencia:** Visualización rápida (*Sparklines*) del comportamiento de los activos en las últimas 24 horas.
* **Soporte Multilingüe:** Cambiador de idioma integrado para una accesibilidad global.

## 🛠️ Tecnologías Utilizadas

* **React** & **TypeScript** - Estructura escalable y lógica de tipado seguro.
* **Vite** - Entorno de desarrollo ultrarrápido y empaquetamiento optimizado.
* **Tailwind CSS** - Estilos modernos, limpios y completamente responsivos para celulares y PC.
* **CoinGecko API** - Conexión fluida con el proveedor líder de datos del mercado financiero.

## 📦 Uso e Instalación Local

Si deseas ejecutar este dashboard en tu computadora local para realizar pruebas o modificaciones, sigue estos pasos:

1. Clona este repositorio en tu máquina.
2. Instala las dependencias necesarias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo local:
   ```bash
   npm run dev
   ```
